# VolleyStats

Tag **serve receive (0–3)** and **serving** from your match video and get player, position and team stats instantly.

## Features (v1)
- Teams and players with positions (OH, OPP, MB, S, L, DS)
- Per-match squad and positions (someone can play a different role on the day)
- Load the match video, tap player → grade. The video time is saved with each tag, so you can jump back to any pass or serve
- Set 1–5 tracking, undo, delete
- Stats: pass average, perfect %, good+ %, aced %, serve average, aces, errors, ace %, error %, in %
- Breakdowns by player, by position, by set, plus season totals and match-by-match trend
- Export CSV (opens in Excel / Google Sheets), backup and restore
- Works offline; all data stays on the device

## Grading
| Grade | Serve receive | Serve |
|---|---|---|
| 3 | Perfect: setter has every option | Ace |
| 2 | Good: setter moves, 2+ hitters available | Tough: opponent out of system |
| 1 | Poor: high ball / free ball only | Easy: opponent runs their offence |
| 0 | Aced / error | Error |

## Get the Android app
Each push to `volleystats/` builds an APK with GitHub Actions
(**Actions → VolleyStats Android APK → latest run → Artifacts → VolleyStats-android-apk**).
Unzip it, copy `app-debug.apk` to the phone and open it (allow "install unknown apps").

## Project layout
- `www/`: the app itself (HTML/CSS/JS, no build step)
- `android/`: native Android project generated by Capacitor
- `assets/`: source icon and splash images

## Develop
```bash
cd volleystats
npm install
npm run serve          # test in a browser at http://localhost:8080
npx cap sync android   # copy www/ changes into the Android project
npx cap open android   # open in Android Studio (to run on a phone or build a release)
```
iPhone: `npm install @capacitor/ios && npx cap add ios` on a Mac with Xcode.
